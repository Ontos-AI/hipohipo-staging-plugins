# Hipohipo 插件 staging 发行

从 Ontos-AI/hipohipo-staging-plugins 注册 marketplace，或从该仓库的 Releases 下载对应客户端的安装包。新版插件 ID 为 hipohipo-staging。已安装旧版 staging 插件的用户，请卸载 staging marketplace 中的旧条目，移除旧 staging marketplace 注册后重新添加该仓库，再安装新条目。

北京 OSS 的 staging 安装索引为 https://ai-bid-server.oss-cn-beijing.aliyuncs.com/hipohipo/staging/releases/latest.json。
